CSV format

One row per base. The generator only reads the columns below — extra columns are ignored, so a richer source-of-truth CSV is fine.

ColumnRequiredMeaning
designationyes Bottom label, e.g. 001א, 113. Mixed ASCII + non-Latin is rendered left-to-right in CSV order.
nameyes Top label — equipment/weapon, e.g. MERKAVA 3, FN MAG, AH-64.
symbolyes Bare APP-6 phrase from the sidebar (armor, infantry, attack helicopter, …). No echelon modifiers.
widthyes Base width in mm. 40 → wide sticker, anything else → 20 mm sticker.
hqno Truthy (1, true, yes) draws a horizontal HQ bar inside the icon.
formationno Groups stickers into one A4 PDF per formation when generating sheets.
groupno Optional sub-grouping label (e.g. company letter).

Example:

designation,name,symbol,width,hq,formation,group
001א,Merkava 3,armor,40,1,1st Armor,א
002,Merkava 3,armor,40,0,1st Armor,א
113,M113 Zelda,armored personnel carrier,20,0,Mech,ב
A1,FN MAG,infantry,20,0,Mech,ב

Pick an affiliation above to change the icon frame (friend / hostile / neutral / unknown). The same CSV works with any affiliation.
